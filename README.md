# React Portfolio SPA

Односторінковий застосунок (SPA), створений на React як навчальний проєкт-портфоліо.

## 🔧 Функціонал
- SPA навігація (React Router)
- Сторінка “Про мене” з проєктами
- Сторінка “Моє місто” з API погоди
- Сторінка “Мій розвиток”
- Темна / світла тема
- Збереження теми в localStorage

## 🧰 Технології
React, JavaScript, HTML, CSS, Weather API
